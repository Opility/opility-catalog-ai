# Screenshot and test evidence

`/screenshots/cropped/`: 15 publication copies of actual user-provided Dify screenshots cropped to focus on app content.

`/private-originals/`: original unedited screenshots (may contain browser sidebar, account details, URLs). This directory is intentionally Git-ignored and **must not** be published without privacy review.

`/tests/`: captured live app transcript; historical functional test log.

`/case-study/`: full chronological build and test documentation / agent-level configuration files.

`/export-inspection/`: evidence extracted from Dify `.ifpkg`. Retained only in the private handoff.

`/screenshot-manifest.json`: captions, sequence and crop metadata.

Honest status: working Dify hosted agent and captured bilingual output. The standalone frontend still requires an authenticated Service API key and deployment tests. No live Shopify publishing.
