# Opility Catalog AI — Dify AI Agent Case Study

**Project:** Opility Catalog AI · Assistant: Ella · Division: Opility AI

**Status:** Functional prototype with documented test evidence

I configured a multilingual product listing assistant using Dify, adapted the template skill into an Opility-branded assistant, and created platform-specific draft guidance for Shopify, Amazon and Shopee. I tracked the setup from original template to branded workflow, including a Build Mode execution error, an old public greeting, and the configuration adjustments used during troubleshooting.

**Observed result:** Ella responded with the intended assistant identity in Build Mode. In one captured sample, the agent generated English and Hebrew Shopify product listings, selling points, descriptions and suggested SEO metadata for a 750 ml stainless-steel water bottle. Product facts stayed consistent and the output included a pre-publication review.

**Tools and competencies:** Dify agent configuration, structured prompts, skill and reference files, localization, product data consistency, QA evidence, issue diagnosis, and documentation.

**Honest scope:** A drafting assistant, not a working Amazon, Shopify or Shopee publishing integration. Test screenshots and raw output logs accompany the case study.
